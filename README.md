## ✨ Key Features & Architecture

- **Modern FinTech / Developer Dark Aesthetic**:
  - Deep obsidian palette (`#0A0D14`) with ambient radial glows (electric cyan & emerald green).
  - Refined glassmorphism cards (`backdrop-filter: blur(16px)`) with delicate `1px solid rgba(255, 255, 255, 0.08)` borders and smooth 3D hover translation.
- **Interactive Project Filtering**:
  - Zero-reload DOM filter categorizing projects into `All Projects`, `AI & APIs`, and `Client Solutions`.
  - Smooth card entry transitions with opacity and vertical translation.
- **3 Core Technical Domains**:
  1. **Front-End Architecture**: HTML5 semantic markup, modern CSS3 Grid & Flexbox, modular ES6+ JavaScript, UI/UX micro-interactions.
  2. **Backend & AI Integration**: Node.js runtime, Vercel Serverless Functions, Google Gemini API, REST APIs, and RSS ingestion pipelines.
  3. **Performance & Analytics**: Google Analytics 4 (GA4) telemetry, Git/GitHub CI/CD, cross-device optimization, and Core Web Vitals.
- **1-Click Email Clipboard Copy**:
  - One-click copy helper writing directly to clipboard with animated floating status toast feedback (*"Email Copied to Clipboard!"*).
- **Responsive Mobile Navigation Drawer**:
  - Smooth slide-out mobile drawer with backdrop blur overlay, escape key dismissal, and link click auto-close.
- **100% Zero-Dependency Architecture**:
  - Built strictly with semantic vanilla web technologies — no heavyweight frameworks, no node_modules build step required for deployment.

## 🛠️ Local Development

Since this project adheres to a pure, zero-dependency architecture, no package installations or build pipelines are required.

### 1. Clone the repository
```bash
git clone https://github.com/ibnusyafrizal15-cmyk/portfolio.git
cd portfolio
```

### 2. Run locally
You can open `index.html` directly in your browser:
```bash
# Windows PowerShell
start index.html

# Or run with any static HTTP server (recommended)
npx serve .
# Or Python
python -m http.server 8000
```

## 📱 Cross-Device Responsiveness

The styling system has been rigorously tested and optimized across all major breakpoints:
- **Ultra-Small Mobile (320px – 380px)**: Compact navigation, fluid typography (`clamp`), no horizontal overflow.
- **Standard Mobile (380px – 540px)**: Full-width interactive touch targets, single-column stacked cards.
- **Tablets & iPads (640px – 1024px)**: Symmetrical 2-column domain and contact grids.
- **Desktop & Ultra-Wide (1024px+)**: Expansive multi-column layouts with ambient glow backdrops.
